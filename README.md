# Payline Email Signature Builder

A clean, modern email signature generator built for Payline employees, ready for Gmail, Apple Mail, and Outlook.

## Features
- **Live Preview:** Instant real-time rendering.
- **Role Presets:** Quick templates for Legal, Engineering, Executive, and Sales.
- **One-Click Copy:** Copy rich HTML or raw source code directly for email clients.
- **Responsive & Dark Mode UI:** Sleek, accessible interface.

## Usage
Open `index.html` in any web browser or host on GitHub Pages.
